# Lessons

The one-line form of every lesson this repo has paid for and has NOT yet gated. Read this file at session start; it is short by construction, because every entry leaves as soon as its gate lands.

Each rule links into [lessons-evidence.md](lessons-evidence.md), which holds the war story and the anchor. Open that only when a rule is in doubt, or the work is in that area; it is not session-start reading.

A new lesson is an entry there plus one line here, and that line names the gate it is waiting for. If you cannot name one, this is not the file: a rule true only here goes to [local-rules.md](../policies/local-rules.md), and one true fleet-wide goes to the fleet's canon candidates.

When the gate lands, prove it red by reintroducing the defect, record that proof with the gate, and delete both halves in the same commit.

## Rules

- A model source may cite a reference photograph only once `docs/research/` records it as viewed at full size and says what it shows, or a guessed form stands beside the photograph that contradicts it. — **gate:** a unit test that every image a file under `src/model/` cites from `interior-images.md` or `exterior-images.md` is an entry marked viewed ([evidence](lessons-evidence.md#a-cited-reference-photograph-must-be-recorded-as-viewed))
